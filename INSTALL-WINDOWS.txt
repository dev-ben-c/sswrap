sswrap - OpenGL wrapper for Starsiege (1999)
https://github.com/dev-ben-c/sswrap

INSTALL
1. Copy opengl32.dll and sswrap.ini into your Starsiege folder, the one that
   contains Starsiege.exe (by default C:\Dynamix\Starsiege).
2. Start Starsiege as usual. Before the game appears, a "display settings" window
   opens. It shows your monitor's resolution; pick:
     - Resolution: leave it on Native.
     - HUD scale: how big the HUD meters are (1.5x is a good start on 1440p and up).
     - Render quality: Native, or 2x/3x supersampling for a sharper, smoother image.
     - Sharper HUD and menu art, ambient occlusion, edge smoothing: leave them on.
     - Ultrawide HUD: on 21:9 and wider screens, keeps the HUD in the middle.
   Click "Start game". Untick "Show this window every time" to stop it appearing;
   set AskOnLaunch=1 in sswrap.ini to get it back.
3. In the game's own video options, keep the OpenGL renderer and fullscreen.

UNINSTALL
Delete opengl32.dll and sswrap.ini from the Starsiege folder (and the
sswrap_textures folder if you made one). If you used Ultrawide HUD, rename
hudLayout.prf.sswrap-orig back to hudLayout.prf to restore your old HUD layout.

NOTES
- Windows may warn about an unknown DLL. It is built from the public source code by
  GitHub's build service; SHA256SUMS.txt lists its checksum.
- The game still checks for its CD. A mounted disc image works, but has no CD music
  (an ISO holds only the data track). To get the music back:
    1. Rip the disc's music tracks to OGG (e.g. with fre:ac, freac.org). Track 1 is
       game data; music starts at track 2.
    2. Make a folder named Music next to Starsiege.exe and put the tracks in it as
       Track02.ogg, Track03.ogg, ... (the disc's track numbers, no gaps).
    3. Download ogg-winmm_binary.zip (github.com/ayuanx/ogg-winmm/releases), copy winmm.dll
       and winmm.ini next to Starsiege.exe.
    4. Turn CD music on in the game's sound options.
  To undo, delete winmm.dll, winmm.ini and the Music folder.
- Problems? sswrap.log (next to the game) records what happened. Please attach it to
  an issue on GitHub.
- Tested with the original retail release (version 1.004) under Wine on Linux.
  Windows and the free Hi-Rez re-release are expected to work but are less tested.
